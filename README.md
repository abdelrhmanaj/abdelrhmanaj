### 🚀 About Me

I am a passionate **Embedded Systems & IoT Engineer** dedicated to building deterministic, memory-efficient firmware, robust connected devices, and deploying intelligent machine learning models right at the edge.

- ⚙️ **Firmware & Low-Level**: Crafting modular, MISRA-compliant Bare-Metal drivers and real-time multi-threaded applications using **FreeRTOS**.
- 📡 **Internet of Things (IoT)**: Designing end-to-end connected architectures with **ESP32 / STM32**, implementing **MQTT**, **HTTP**, and **BLE** for reliable telemetry and control.
- 🧠 **Edge AI & TinyML**: Bringing artificial intelligence to resource-constrained microcontrollers using **TensorFlow Lite for Microcontrollers (TFLite Micro)** and **Edge Impulse**.
- 🔬 **Hardware-Software Co-Design**: Experienced with communication buses (**CAN, SPI, I2C, UART**), sensor integration, memory management, and digital logic with **Verilog/VHDL**.
